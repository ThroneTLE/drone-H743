# R-PARAM-1 在线参数名称收口

本项由作者明确授权：上位机遗留旧参数全部替换，固件不再兼容旧名称。
起点为 `06f5818a`，开工工作区干净；本报告是软件交审材料，不是实机验收。

## 实现与边界

- Driver 只按当前参数表读写，删除六个单环增益别名的乘积、除法和惯量换算分支。未知名称返回失败，参数值不变。当前默认值、控制律、符号、限幅和安全门未改。
- 上位机快速编辑改为位置 P、速度 PID、角度 P、角速度 PID 四页，共 24 个独立增益；一律发送当前 `PARAM SET coax.*`，保留草稿、待确认和回读状态。位置/速度的 X、Y、Z 各自独立。
- 固件旧 PID 查询/设置明确返回 ERR，裸旧滑块名称不再分派。原 function ID 不复用，帧头、CRC 和参数回复文本不变。AIWB2 仍透传当前完整 `coax.*` 参数行。
- 遥测 schema v4 保留旧槽位编号 7/8/9/10/18/19/21，名称为 reserved，参数绑定为空、采样值为零。现代增益通道继续使用已有编号，其他通道不移动；hash 覆盖本次元数据变化。默认 12 路实时量、27 路参数，稳态 81 B、全量刷新 197 B，40 Hz 共 3356 B/s，占 57600 baud 的 58.3%。
- 已保存的旧仪表盘绑定单向迁移到新通道，丢弃旧增益值、量程和标题设置；迁移不参与线上写入。旧位置积分没有对应现代参数，移除该绑定，不能偷偷解释成速度积分。
- IDENT APPLY 明确使用 `rate_kp`。原执行器阶跃拟合的单环 KP/KD 不能直接作为当前四环参数，界面保留响应分析及调参说明，不再执行旧 Apply。独立姿态分析脚本输出 P-P 等效参数 `att_kp = kr/kw`、`rate_kp = kw`，标明只适用于角速度 I/D 为零的等效假设，不能当作自动整定结论。
- Flash CFG V18/V17/V16/V15 的结构读取和历史 FlightLog 解码保持原语义。这是文件版本读取，不是固件在线旧名称兼容。未读写实际飞控 Flash，未打开串口，未烧录或复位。

## 架构三件套

Contract：固件当前参数表为名称/数值校验来源；UI 按能力表校验并发送当前参数，只有真实回读更新目标状态。

Boundary：Tk 布局放在新的 `cascade_editor.py`，旧布局迁移是独立纯数据模块；不新增线程、硬件访问或控制器算法。两个禁止增长的入口文件均缩减。

Test seam：真实 C DLL 逐个拒绝旧名且保持状态，24 项增益真实 TCP 往返，新 UI 三尺寸×三缩放，schema 实际 C 输出与 Python hash/解码，既有 CRC/分包/坏帧/流策略和完整回归。
