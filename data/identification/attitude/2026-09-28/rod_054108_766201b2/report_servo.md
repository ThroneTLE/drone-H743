# 杆上辨识：舵机单独（电机不转）

【舵机与反作用（电机不转）】

反作用惯量 J：-0.04070 kg·m²（±17702%；模型 I_杆·θ̈ + c·θ̇ + K·θ = −J·s̈，负号 = 舵机加速把机体推向推力力矩的同一方向，带桨时形成 TWD 凹口）

舵机响应：5.8 Hz（ωs = 36.6 rad/s），阻尼比 0.10（空载：电机不转，没有桨的气动负载）

纯延迟：46.6 ms；1 Hz 等效延迟 52.3 ms

预测带桨反作用力偶 ρ_pred = −J/(|L|·T) = 0.03348 s²（本轮固件沿杆轴力臂 |L| = 0.1082 m，悬停推力 T = 11.24 N；与带桨拟合的 ρ 同一约定）

同组（同一天、同杆轴、同杆高）还没有带桨 TWD 拟合可对照。

【台架】

绕杆惯量 I_杆 = K/(2π·f摆)² = 1.10721 kg·m²；摆频 0.126 Hz；绕杆阻尼 c = 22.1439 N·m·s

回中刚度 K = 0.6943 N·m/rad（挂砝码实测，或没填时 m·g·d）

静态重力偏心 H = +0.8682 N·m/rad（倾转组件质心不在舵机轴上，倾转时绕杆多出 H·s；只在杆上有，已单独拟合，不混进 I_杆 与 J）；量级参考：servo_motor 组件 348.6 g、质心离舵机轴 0.114 m → m·g·r ≈ 0.390 N·m/rad（整个组件都随舵机倾转时的上限）

【诊断】

拟合度（12 Hz 以下，去掉开头 0.5 s）：3.2%；样本 2006；指令摆幅 2.98°

提醒：反作用惯量 J = -0.04070 kg·m²（模型 I_杆·θ̈ + c·θ̇ + K·θ = −J·s̈）：舵机加速把机体推向推力力矩的同一方向（带桨时就是 TWD 凹口）；静态重力偏心 H = +0.8682 N·m/rad（倾转组件质心不在舵机轴上，倾转时绕杆多出 H·s，朝推力力矩正向；约为回中刚度 K 的 125%）：已在模型里单独拟合，不再混进 I_杆 与 J。它只在杆上有，飞行时绕质心转不产生；ζs 贴到拟合边界：激励没把舵机转折频率附近激出来，舵机二阶与纯延迟分不开，只有 1 Hz 等效延迟可信；带内（12 Hz 以下、0.5 s 之后）拟合优度只有 3.2%，模型没有描述住这段数据（回差、线缆或台架模态）；J 的相对不确定度约 17702%：加大舵机摆幅或加长激励重测。

不可信：带内拟合优度 3% 低于 72%。

推力来自当前标定查表，力矩来自最终脉宽反算；均不是直接测力矩。这一个转轴不能独立分离两个舵机的延迟，也不能证明最佳 PID。
