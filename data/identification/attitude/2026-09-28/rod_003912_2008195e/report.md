# 杆上辨识：本轮拟合

本轮陷波（桨叶振动）：开（开跑时 待命，极对数 7）；FF / 舵机单独轮是开环激励，不经过陷波

本轮舵机回差补偿：开（横滚 20 / 俯仰 20 mrad，换向迟滞 5 mrad）

几何：杆到质心 d = 0.062 m；俯仰倾转轴到质心 -0.108 m；横滚倾转轴到质心 -0.108 m（飞控到质心 +0.022 m 取自那一轮）

【给 PID 用的】

整定惯量：0.037637 kg·m²（不确定度 ±6%）

1 Hz 等效延迟：50.4 ms（舵机响应和纯延迟合起来，在 1 Hz 摆动时相当于晚了多久）

建议参数的裕度：增益裕度 7.6 dB / 相位裕度 61° / 穿越 0.98 Hz（增益裕度 ≥6 dB、相位裕度 ≥45° 才算稳）

【对象特性】

舵机响应：3.5 Hz，阻尼比 0.23（舵机跟上指令角度有多快、会不会过冲）

纯延迟：28.2 ms（指令发出到舵机开始动的时间）

反作用力矩系数 ρ：0.00598 s²（舵机甩动电机组件时机体被反推的程度，飞行时也存在）

“尾巴摇狗”零点：台架 2.5 Hz / 飞行 2.0 Hz（比这更快的指令，机体会先往反方向动一下）

摆动固有频率：0.66 Hz（机体在杆上自己摆的快慢）

力矩模型标定系数 κ：0.956（1 = 固件的力矩模型准确）

杆上惯量（绕杆）：0.040364 kg·m²；飞行惯量（绕质心）：0.03599 kg·m²

杆到质心距离（你量的输入）：61.8 mm

【诊断】

拟合度（4 Hz 以下，去掉开头 0.5 s）：84.7%

15 Hz 全频段 83.0%（含碳杆约 9 Hz 台架抖动，只作参考）

刚体模型读数：整定惯量 0.071474 kg·m²、延迟 54.3 ms、拟合度 75.3%，仅供对比，不用于整定

提醒：刚体积分读数：被 6/10 Hz 谱线证伪，不用于整定（整定惯量 0.0715 kg·m²、延迟 54.3 ms、4 Hz 带内拟合 75.3%）；绕杆阻尼 c = 0.0084 N·m·s（摆的阻尼比约 0.03）只进拟合：它只在摆频附近看得出来，与舵机滞后、延迟在更高频段不可分，整定阻尼按 0（保守）；15 Hz 带宽下的拟合优度 83.0% 只作诊断：约 11–14 Hz 的台架/杆弹性次要模态不在模型里。

舵机单独交叉核对（rod_000415_ac58f4d7，空载）：J = -0.00360 kg·m²（按本次回中刚度折算）→ 预测 ρ_pred = 0.0045 s²，本次拟合 ρ = 0.005983 s²（预测/拟合 = 0.75）；舵机 39.0 rad/s / 阻尼比 0.90 / 纯延迟 26.3 ms。只作核对，没有钉进拟合。静态重力偏心 H = +0.0820 N·m/rad 在带桨轮里折成 H/(|L|·T) = +0.102（固件力矩单位），混在推力增益 G 里：本次 G = κ·尺度 = 1.502，其中约 +7% 来自 H；k 的几何核对没有扣掉这一项，看 k 时把它考虑进去。

推力来自当前标定查表，力矩来自最终脉宽反算；均不是直接测力矩。这一个转轴不能独立分离两个舵机的延迟，也不能证明最佳 PID。
