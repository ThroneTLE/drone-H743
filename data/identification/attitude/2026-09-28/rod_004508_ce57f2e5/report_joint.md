# 杆上辨识：联合 2 轮

联合 2 轮：rod_004508_ce57f2e5、rod_003912_2008195e（用当前填写的几何）

几何：杆到质心 d = 0.062 m；俯仰倾转轴到质心 -0.108 m；横滚倾转轴到质心 -0.108 m（飞控到质心 +0.022 m 取自那一轮）

【给 PID 用的】

整定惯量：0.035987 kg·m²（不确定度 ±4%）

1 Hz 等效延迟：55.3 ms（舵机响应和纯延迟合起来，在 1 Hz 摆动时相当于晚了多久）

建议参数的裕度：增益裕度 6.0 dB / 相位裕度 58° / 穿越 1.04 Hz（增益裕度 ≥6 dB、相位裕度 ≥45° 才算稳）

【对象特性】

舵机响应：3.6 Hz，阻尼比 0.27（舵机跟上指令角度有多快、会不会过冲）

纯延迟：29.9 ms（指令发出到舵机开始动的时间）

反作用力矩系数 ρ：0.00616 s²（舵机甩动电机组件时机体被反推的程度，飞行时也存在）

“尾巴摇狗”零点：台架 2.5 Hz / 飞行 2.0 Hz（比这更快的指令，机体会先往反方向动一下）

摆动固有频率：0.66 Hz（机体在杆上自己摆的快慢）

力矩模型标定系数 κ：0.997（1 = 固件的力矩模型准确）

杆上惯量（绕杆）：0.040245 kg·m²；飞行惯量（绕质心）：0.035871 kg·m²

杆到质心距离（你量的输入）：61.8 mm

【诊断】

拟合度（4 Hz 以下，去掉开头 0.5 s）：82.6%

15 Hz 全频段 81.3%（含碳杆约 9 Hz 台架抖动，只作参考）

逐轮拟合度：82.6% / 83.9%

刚体模型读数：整定惯量 0.070251 kg·m²、延迟 58.7 ms、拟合度 74.7%，仅供对比，不用于整定

提醒：2 轮联合拟合：共享 I_杆、G、T、ωs、ζs、ρ，每轮各自解初值与零偏；逐轮带内拟合优度 82.6% / 83.9%；刚体积分读数：被 6/10 Hz 谱线证伪，不用于整定（整定惯量 0.0703 kg·m²、延迟 58.7 ms、4 Hz 带内拟合 74.7%）；绕杆阻尼 c = 0.0098 N·m·s（摆的阻尼比约 0.03）只进拟合：它只在摆频附近看得出来，与舵机滞后、延迟在更高频段不可分，整定阻尼按 0（保守）；各轮力矩 rms 相差 2.0 倍（0.101 / 0.050 N·m）：舵机回差让小幅值轮的等效增益偏低、滞后偏大，一组线性参数描述不了两种工况；幅值相当的轮次再联合；15 Hz 带宽下的拟合优度 81.3% 只作诊断：约 11–14 Hz 的台架/杆弹性次要模态不在模型里。

舵机单独交叉核对（rod_000415_ac58f4d7，空载）：J = -0.00360 kg·m²（按本次回中刚度折算）→ 预测 ρ_pred = 0.0045 s²，本次拟合 ρ = 0.006159 s²（预测/拟合 = 0.73）；舵机 39.0 rad/s / 阻尼比 0.90 / 纯延迟 26.3 ms。只作核对，没有钉进拟合。静态重力偏心 H = +0.0820 N·m/rad 在带桨轮里折成 H/(|L|·T) = +0.102（固件力矩单位），混在推力增益 G 里：本次 G = κ·尺度 = 1.566，其中约 +7% 来自 H；k 的几何核对没有扣掉这一项，看 k 时把它考虑进去。

推力来自当前标定查表，力矩来自最终脉宽反算；均不是直接测力矩。这一个转轴不能独立分离两个舵机的延迟，也不能证明最佳 PID。
