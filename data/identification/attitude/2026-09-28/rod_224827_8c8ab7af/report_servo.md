# 杆上辨识：舵机单独（电机不转）

【舵机与反作用（电机不转）】

反作用惯量 J：-0.00531 kg·m²（±7%；模型 I_杆·θ̈ + c·θ̇ + K·θ = −J·s̈，负号 = 舵机加速把机体推向推力力矩的同一方向，带桨时形成 TWD 凹口）

舵机响应：5.0 Hz（ωs = 31.4 rad/s），阻尼比 0.46（空载：电机不转，没有桨的气动负载）

纯延迟：8.9 ms；1 Hz 等效延迟 38.8 ms

预测带桨反作用力偶 ρ_pred = −J/(|L|·T) = 0.00437 s²（本轮固件沿杆轴力臂 |L| = 0.1082 m，悬停推力 T = 11.24 N；与带桨拟合的 ρ 同一约定）

对照同组最近的带桨 TWD 拟合（rod_063555_33693d51）：ρ = 0.006092 s²；按那轮固件力臂 0.1082 m、推力 7.40 N 预测 0.006635 s²（预测/拟合 = 1.09）；舵机 26.0 rad/s / 阻尼比 0.29 / 纯延迟 18.8 ms（带桨）。只作交叉核对，没有钉进带桨拟合。

【台架】

绕杆惯量 I_杆 = K/(2π·f摆)² = 0.04072 kg·m²；摆频 0.657 Hz（取同组带桨拟合 rod_063555_33693d51：舵机单独激不起杆摆，摆频不在这里拟合）；绕杆阻尼 c = 0.0792 N·m·s

回中刚度 K = 0.6943 N·m/rad（挂砝码实测，或没填时 m·g·d）

静态重力偏心 H = +0.8577 N·m/rad（倾转组件质心不在舵机轴上，倾转时绕杆多出 H·s；只在杆上有，已单独拟合，不混进 I_杆 与 J）；量级参考：servo_motor 组件 348.6 g、质心离舵机轴 0.114 m → m·g·r ≈ 0.390 N·m/rad（整个组件都随舵机倾转时的上限）

【幅值依赖（同组舵机单独轮）】

摆幅 1.5°：J = -0.00531 kg·m²，纯延迟 8.9 ms，1 Hz 等效延迟 38.8 ms

摆幅 3.0°：J = -0.00263 kg·m²，纯延迟 36.5 ms，1 Hz 等效延迟 41.1 ms

摆幅 3.0°：J = -0.00122 kg·m²，纯延迟 0.0 ms，1 Hz 等效延迟 132.2 ms

摆幅 10.0°：J = -0.00431 kg·m²，纯延迟 2.7 ms，1 Hz 等效延迟 69.9 ms

摆幅 10.0°：J = -0.00363 kg·m²，纯延迟 17.8 ms，1 Hz 等效延迟 67.2 ms

大幅值极限 J∞ = -0.00289 kg·m²；回差半宽 b ≈ —；纯延迟 T(A) = 13.2 ms + -0.00 ms·rad / A

方法：回差按间隙 ±b 的迟滞环处理。双脉冲是方波式指令，每次换向舵机先走完空程 b 才带动组件，一次谐波（描述函数）增益 N(A) ≈ 1 − b/A，所以表观 J(A) = J·(1 − b/A)：对 1/A 做线性回归，截距是大幅值极限 J，斜率是 −J·b。纯延迟同理随 1/A 变大（先走空程），另报 T(A) 对 1/A 的回归。前提：小角度、方波近似；正弦激励的描述函数不同，只作量级。

小幅值的 |J| 不比大幅值小：这几轮看不出回差（或被其它非线性盖过），b 不报。

【诊断】

拟合度（12 Hz 以下，去掉开头 0.5 s）：58.9%；样本 4928；指令摆幅 1.49°

提醒：反作用惯量 J = -0.00531 kg·m²（模型 I_杆·θ̈ + c·θ̇ + K·θ = −J·s̈）：舵机加速把机体推向推力力矩的同一方向（带桨时就是 TWD 凹口）；静态重力偏心 H = +0.8577 N·m/rad（倾转组件质心不在舵机轴上，倾转时绕杆多出 H·s，朝推力力矩正向；约为回中刚度 K 的 124%）：已在模型里单独拟合，不再混进 I_杆 与 J。它只在杆上有，飞行时绕质心转不产生；I_杆 按给定值钉死为 0.04072 kg·m²，摆频不拟合；带内（12 Hz 以下、0.5 s 之后）拟合优度只有 58.9%，模型没有描述住这段数据（回差、线缆或台架模态）。

不可信：带内拟合优度 59% 低于 72%。

推力来自当前标定查表，力矩来自最终脉宽反算；均不是直接测力矩。这一个转轴不能独立分离两个舵机的延迟，也不能证明最佳 PID。
