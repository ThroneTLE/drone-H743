# 杆上辨识：本轮拟合

本轮陷波（桨叶振动）：关（开跑时 关，极对数 7）；FF / 舵机单独轮是开环激励，不经过陷波

本轮舵机回差补偿：关

几何：杆到质心 d = 0.062 m；俯仰倾转轴到质心 -0.108 m；横滚倾转轴到质心 -0.108 m（飞控到质心 +0.022 m 取自那一轮）

【给 PID 用的】

整定惯量：0.20249 kg·m²（不确定度 ±18%）

1 Hz 等效延迟：91.4 ms（舵机响应和纯延迟合起来，在 1 Hz 摆动时相当于晚了多久）

建议参数的裕度：增益裕度 9.4 dB / 相位裕度 68° / 穿越 0.34 Hz（增益裕度 ≥6 dB、相位裕度 ≥45° 才算稳）

【对象特性】

舵机响应：5.8 Hz，阻尼比 0.20（舵机跟上指令角度有多快、会不会过冲）

纯延迟：80.0 ms（指令发出到舵机开始动的时间）

反作用力矩系数 ρ：-0.000821 s²（舵机甩动电机组件时机体被反推的程度，飞行时也存在）

“尾巴摇狗”零点：台架 — / 飞行 —（比这更快的指令，机体会先往反方向动一下）

摆动固有频率：0.67 Hz（机体在杆上自己摆的快慢）

力矩模型标定系数 κ：0.174（1 = 固件的力矩模型准确）

杆上惯量（绕杆）：0.039517 kg·m²；飞行惯量（绕质心）：0.035143 kg·m²

杆到质心距离（你量的输入）：61.8 mm

【诊断】

拟合度（4 Hz 以下，去掉开头 0.5 s）：65.4%

15 Hz 全频段 65.1%（含碳杆约 9 Hz 台架抖动，只作参考）

刚体模型读数：整定惯量 0.12401 kg·m²、延迟 90.0 ms、拟合度 57.4%，仅供对比，不用于整定

提醒：刚体积分读数：被 6/10 Hz 谱线证伪，不用于整定（整定惯量 0.1240 kg·m²、延迟 90.0 ms、4 Hz 带内拟合 57.4%）；绕杆阻尼 c = 0.0212 N·m·s（摆的阻尼比约 0.06）只进拟合：它只在摆频附近看得出来，与舵机滞后、延迟在更高频段不可分，整定阻尼按 0（保守）；15 Hz 带宽下的拟合优度 65.1% 只作诊断：约 11–14 Hz 的台架/杆弹性次要模态不在模型里；带内（12 Hz 以下、0.5 s 之后）拟合优度只有 65.4%，模型没有描述住这段数据；整定惯量 I_cg/κ 的相对不确定度约 18%，超过 8%：加长激励或加大幅值重测；推力×舵机模型比例 k = κ/κ_几何 = 0.17（±18%）不在 0.7–1.4：推力查补表、舵机角度标定或倾转轴/杆高测量有误，或小幅值激励落在舵机回差里，先核对；反作用力偶 ρ = -0.00082 s² 不为正：没有 TWD 零点，按实数零点处理。

舵机单独交叉核对（rod_063030_8daef889，空载）：J = -0.00343 kg·m²（按本次回中刚度折算）→ 预测 ρ_pred = 0.004283 s²，本次拟合 ρ = -0.0008205 s²（预测/拟合 = -5.22）；舵机 40.0 rad/s / 阻尼比 0.57 / 纯延迟 23.7 ms。只作核对，没有钉进拟合。静态重力偏心 H = +0.1236 N·m/rad 在带桨轮里折成 H/(|L|·T) = +0.154（固件力矩单位），混在推力增益 G 里：本次 G = κ·尺度 = 0.273，其中约 +57% 来自 H；k 的几何核对没有扣掉这一项，看 k 时把它考虑进去。

推力来自当前标定查表，力矩来自最终脉宽反算；均不是直接测力矩。这一个转轴不能独立分离两个舵机的延迟，也不能证明最佳 PID。
