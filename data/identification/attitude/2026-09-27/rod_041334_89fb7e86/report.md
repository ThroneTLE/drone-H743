# 杆上辨识：本轮拟合

几何：杆到质心 d = 0.135 m；俯仰倾转轴到质心 -0.035 m；横滚倾转轴到质心 没填（飞控到质心 +0.095 m 取自那一轮）

【给 PID 用的】

整定惯量：0.12445 kg·m²（不确定度 ±14%）

1 Hz 等效延迟：79.5 ms（舵机响应和纯延迟合起来，在 1 Hz 摆动时相当于晚了多久）

建议参数的裕度：增益裕度 6.0 dB / 相位裕度 71° / 穿越 0.29 Hz（增益裕度 ≥6 dB、相位裕度 ≥45° 才算稳）

【对象特性】

固件算的倾转力矩和实际不符：固件力矩模型高估俯仰操纵力矩约 2.3 倍（几何预测 κ = 0.430，实测 0.367，二者一致）；整定已按 κ 折算，飞行中其它用到力矩模型的地方（前馈、限幅）同样偏差。

舵机响应：13.5 Hz，阻尼比 1.26（舵机跟上指令角度有多快、会不会过冲）

纯延迟：50.0 ms（指令发出到舵机开始动的时间）

反作用力矩系数 ρ：0.00308 s²（舵机甩动电机组件时机体被反推的程度，飞行时也存在）

“尾巴摇狗”零点：台架 3.8 Hz / 飞行 1.7 Hz（比这更快的指令，机体会先往反方向动一下）

摆动固有频率：0.65 Hz（机体在杆上自己摆的快慢）

力矩模型标定系数 κ：0.367（1 = 固件的力矩模型准确）

杆上惯量（绕杆）：0.059396 kg·m²；飞行惯量（绕质心）：0.045733 kg·m²

杆到质心距离（你量的输入）：134.6 mm

【诊断】

拟合度（4 Hz 以下，去掉开头 0.5 s）：52.1%

15 Hz 全频段 51.8%（含碳杆约 9 Hz 台架抖动，只作参考）

刚体模型读数：整定惯量 0.17868 kg·m²、延迟 73.8 ms、拟合度 73.6%，仅供对比，不用于整定

提醒：刚体积分读数：被 6/10 Hz 谱线证伪，不用于整定（整定惯量 0.1787 kg·m²、延迟 73.8 ms、4 Hz 带内拟合 73.6%）；绕杆阻尼 c = 0.0362 N·m·s（摆的阻尼比约 0.07）只进拟合：它只在摆频附近看得出来，与舵机滞后、延迟在更高频段不可分，整定阻尼按 0（保守）；15 Hz 带宽下的拟合优度 51.8% 只作诊断：约 11–14 Hz 的台架/杆弹性次要模态不在模型里；带内（12 Hz 以下、0.5 s 之后）拟合优度只有 52.1%，模型没有描述住这段数据；整定惯量 I_cg/κ 的相对不确定度约 14%，超过 8%：加长激励或加大幅值重测。

推力来自当前标定查表，力矩来自最终脉宽反算；均不是直接测力矩。这一个转轴不能独立分离两个舵机的延迟，也不能证明最佳 PID。
