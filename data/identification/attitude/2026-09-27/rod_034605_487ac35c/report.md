# 杆上辨识：本轮拟合

几何：杆到质心 d = 0.135 m；俯仰倾转轴到质心 +0.225 m；横滚倾转轴到质心 没填（飞控到质心 +0.095 m 取自那一轮）

【给 PID 用的】

整定惯量：0.0066924 kg·m²（不确定度 ±4%）

1 Hz 等效延迟：74.8 ms（舵机响应和纯延迟合起来，在 1 Hz 摆动时相当于晚了多久）

建议参数的裕度：增益裕度 11.8 dB / 相位裕度 45° / 穿越 1.25 Hz（增益裕度 ≥6 dB、相位裕度 ≥45° 才算稳）

【对象特性】

舵机响应：5.0 Hz，阻尼比 0.58（舵机跟上指令角度有多快、会不会过冲）

纯延迟：36.8 ms（指令发出到舵机开始动的时间）

反作用力矩系数 ρ：0.00852 s²（舵机甩动电机组件时机体被反推的程度，飞行时也存在）

“尾巴摇狗”零点：台架 2.7 Hz / 飞行 4.3 Hz（比这更快的指令，机体会先往反方向动一下）

摆动固有频率：0.67 Hz（机体在杆上自己摆的快慢）

力矩模型标定系数 κ：6.284（1 = 固件的力矩模型准确）

杆上惯量（绕杆）：0.055715 kg·m²；飞行惯量（绕质心）：0.042052 kg·m²

杆到质心距离（你量的输入）：134.6 mm

【诊断】

拟合度（4 Hz 以下，去掉开头 0.5 s）：85.4%

15 Hz 全频段 83.1%（含碳杆约 9 Hz 台架抖动，只作参考）

刚体模型读数：整定惯量 0.013746 kg·m²、延迟 73.4 ms、拟合度 74.7%，仅供对比，不用于整定

提醒：刚体积分读数：被 6/10 Hz 谱线证伪，不用于整定（整定惯量 0.0137 kg·m²、延迟 73.4 ms、4 Hz 带内拟合 74.7%）；绕杆阻尼 c = 0.0223 N·m·s（摆的阻尼比约 0.05）只进拟合：它只在摆频附近看得出来，与舵机滞后、延迟在更高频段不可分，整定阻尼按 0（保守）；15 Hz 带宽下的拟合优度 83.1% 只作诊断：约 11–14 Hz 的台架/杆弹性次要模态不在模型里；力矩极性不一致（κ = 6.28，几何预测 -2.72）：固件认为的倾转力矩方向与实测相反，先核对倾转轴高度与推力点位置。

推力来自当前标定查表，力矩来自最终脉宽反算；均不是直接测力矩。这一个转轴不能独立分离两个舵机的延迟，也不能证明最佳 PID。
