# 杆上辨识：联合 4 轮

联合 4 轮：rod_041353_b932d1c9、rod_041334_89fb7e86、rod_041316_fb87d959、rod_041250_7cad3fb3（用当前填写的几何）

几何：杆到质心 d = 0.135 m；俯仰倾转轴到质心 -0.035 m；横滚倾转轴到质心 -0.035 m（飞控到质心 +0.095 m 取自那一轮）

【给 PID 用的】

整定惯量：0.12408 kg·m²（不确定度 ±10%）

1 Hz 等效延迟：92.6 ms（舵机响应和纯延迟合起来，在 1 Hz 摆动时相当于晚了多久）

建议参数的裕度：增益裕度 6.0 dB / 相位裕度 67° / 穿越 0.34 Hz（增益裕度 ≥6 dB、相位裕度 ≥45° 才算稳）

【对象特性】

固件算的倾转力矩和实际不符：固件力矩模型高估俯仰操纵力矩约 2.3 倍（几何预测 κ = 0.430，实测 0.332，二者一致）；整定已按 κ 折算，飞行中其它用到力矩模型的地方（前馈、限幅）同样偏差。

舵机响应：12.9 Hz，阻尼比 1.50（舵机跟上指令角度有多快、会不会过冲）

纯延迟：55.9 ms（指令发出到舵机开始动的时间）

反作用力矩系数 ρ：0.003 s²（舵机甩动电机组件时机体被反推的程度，飞行时也存在）

“尾巴摇狗”零点：台架 3.7 Hz / 飞行 1.7 Hz（比这更快的指令，机体会先往反方向动一下）

摆动固有频率：0.68 Hz（机体在杆上自己摆的快慢）

力矩模型标定系数 κ：0.332（1 = 固件的力矩模型准确）

杆上惯量（绕杆）：0.054899 kg·m²；飞行惯量（绕质心）：0.041236 kg·m²

杆到质心距离（你量的输入）：134.6 mm

【诊断】

拟合度（4 Hz 以下，去掉开头 0.5 s）：10.1%

15 Hz 全频段 10.3%（含碳杆约 9 Hz 台架抖动，只作参考）

逐轮拟合度：64.8% / 50.2% / 31.3% / 10.1%

刚体模型读数：整定惯量 0.2097 kg·m²、延迟 88.6 ms、拟合度 11.1%，仅供对比，不用于整定

提醒：4 轮联合拟合：共享 I_杆、G、T、ωs、ζs、ρ，每轮各自解初值与零偏；逐轮带内拟合优度 64.8% / 50.2% / 31.3% / 10.1%；刚体积分读数：被 6/10 Hz 谱线证伪，不用于整定（整定惯量 0.2097 kg·m²、延迟 88.6 ms、4 Hz 带内拟合 11.1%）；绕杆阻尼 c = 0.0464 N·m·s（摆的阻尼比约 0.10）只进拟合：它只在摆频附近看得出来，与舵机滞后、延迟在更高频段不可分，整定阻尼按 0（保守）；舵机二阶的 ζs 贴到拟合边界：这段激励分不开舵机滞后与纯延迟（激励上限没越过舵机转折频率），只有 1 Hz 等效延迟可信，10 Hz 附近的回路增益是外推。扫频终点提高到 12 Hz 以上，或与双脉冲轮联合拟合；各轮力矩 rms 相差 6.8 倍（0.101 / 0.050 / 0.031 / 0.015 N·m）：舵机回差让小幅值轮的等效增益偏低、滞后偏大，一组线性参数描述不了两种工况；幅值相当的轮次再联合；模型无关频响量到的摆频 0.58 Hz，模型 0.68 Hz（相差 +18%）；15 Hz 带宽下的拟合优度 10.3% 只作诊断：约 11–14 Hz 的台架/杆弹性次要模态不在模型里；带内（12 Hz 以下、0.5 s 之后）拟合优度只有 10.1%，模型没有描述住这段数据；整定惯量 I_cg/κ 的相对不确定度约 10%，超过 8%：加长激励或加大幅值重测。

推力来自当前标定查表，力矩来自最终脉宽反算；均不是直接测力矩。这一个转轴不能独立分离两个舵机的延迟，也不能证明最佳 PID。
