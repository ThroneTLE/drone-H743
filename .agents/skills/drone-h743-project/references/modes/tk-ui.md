# 类别模式：tk-ui

来源：`data/analysis/tk_revamp/2026-09-04/handoff/TK_UI_MODE.md`（改版交接稿草案），
2026-09-04 由作者派发 TK 批次时安装。本文件是该类别的权威授权边界。

## 适用

Tkinter/ttk 上位机的主题、布局、可达性、输入、页面状态、绘图、记录/导出与可用性测试。线上字段/字节格式变化还需叠加 `protocol-telemetry`；算法结论仍受 `algorithm-validation` 约束。

## 授权范围

- 按作者选定 REQ 修改 `tools/panel_lib/`，新增 UI/参数草稿/记录服务模块，增加 `tests/` 契约与离线 QA 工具。
- 允许从 `tools/drone_tcp_panel.py` 抽取对应职责并作薄挂载，整文件只减不增。不得借布局改动复制另一套连接/轮询/状态管理。
- 允许模拟 transport、故障注入、同一数据的主机回放，允许独立无硬件 QA 窗口截图。
- 文案、布局、视觉目标只作用于上位机体验；不赋予目标板命令授权。

## 必须保持

1. 连接代次、接收时间、有效性与 frame provenance 不因显示重画而改变；未知/失效/过期不得伪装为零值或成功。
2. 拆桨检查、快照新鲜度、armed/输出安全门和现有坐标符号不放宽。拒绝的执行器动作不得在恢复连接后自动补发。
3. 参数目标值、草稿、待确认、RAM/Flash 状态分开；回包不覆盖用户尚未发送的草稿。
4. CSV/证据文件不静默覆盖；schema/连接变化、丢弃、写入失败必须可观测。
5. 活动页面的关键控件可见或能正常滚动到达；停止动作不能藏在不可滚动裁切区。
6. 录制、慢 I/O、分析不阻塞 Tk 主线程。后台线程不操作 Tk widget；只通过明确的状态/事件边界发布结果。

## 测试与判据

- 全局禁止测试打开真实串口或调用烧录/复位程序；用户 panel_state、日志与历史证据目录全部隔离。单个 FakeTransport 测试不能替代全局护栏。
- 用真实 DronePanel/实际模块方法检查功能，不仅做字符串断言。协议夹具来自固件格式串、真实 C 编码器或注明出处的实录。
- 至少覆盖报告的三尺寸三缩放模拟矩阵；真实多屏 DPI 切换另列人工检查，不能由模拟冒充。
- 主题控件检查 normal/focus/disabled/readonly/invalid；滚轮、Tab、Enter、Escape、取消与重复点击均有相应用例。
- 测试应覆盖断开、无快照、过期、拒绝、超时、异常、恢复；不能只测一路正常数据。
- 已批准布局变化可以替换过时的纯搬移 AST 快照，但必须保留原契约的保障，记录替代测试；禁止无说明删除保护。
- 每项行为改动带契约；交付按仓库规则全量 pytest、Debug 构建零警告、索引检查与 PIPELINE 契约。性能目标采用正式 REQ 中明确的测试条件，不在结果出来后抬阈值。

## 禁止

- 不迁移 GUI 框架，不引入新的一套应用/后台服务器，不改 CubeMX 或控制固件以掩盖 UI 问题。
- 不动历史 `data/calibration/**`，不改算法、标定阈值、执行器极性、FLU 迁移掩码，不解冻 S4/S5/M7。
- 不将“已排队/本地值变化”写成“飞控已应用/已保存 Flash”。不因其他报文到达就替一条写命令确认成功。
- 不通过增加串口/快照超时、扩大队列、吞异常来宣称流畅性修复。

## 交付物

按 REQ 提交、置待审核；附前后截图、最小复现、协议来源、测试原文、同数据性能对比、文件来源/完整性记录、已知限制与进入的工作模式。实机复核由审核者执行。
