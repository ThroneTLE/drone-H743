## 授权与边界

- 在 `tools/sim_xz/` 新建独立 Python/Tk 仿真程序，通过本机 TCP 客户端连接现有上位机服务端。此独立进程明确作为 `tk-ui.md` 禁止新增后台服务器/应用条款的本项例外；其余 UI 线程、状态、测试和记录约束继续适用。
- 通过薄 C DLL 包装复用当前四环控制器、分配器与宿主调度器；允许改变仿真进程内参数，不改固件默认值、控制律、安全门、坐标符号或运行时掩码。Python 不复制 PID、参数换算和分配公式。
- 允许 X/Z/俯仰物理模型、执行器动态、理想反馈、合成阶跃与 A/B 实验；它们验证教学工具行为，不用于证明实机算法收敛、性能达标、校准完成或飞行放行。真实算法结论仍遵守实录数据规则。
- 允许新增协议适配、仿真 schema、现有参数读写和遥测的最小设备端实现；沿用线上格式、ID、CRC与回显语义，不伪装 Flash 或硬件操作成功。夹具锚定真实固件/编码器。
- 合成产物显式标注 simulation，经 `tools/project_paths.py` 登记独立数据目录；先读 `data/README.md`。不得修改历史 `data/calibration/**`。
- 禁止串口/烧录/复位/目标板命令；测试仅本机回环与隔离设备桩。禁止两个巨型文件增长，不手改 CubeMX 文件。

## 架构三件套

- Contract：物理状态 x/z/vx/vz/pitch/pitch_rate 与执行器状态，FLU、SI、显式仿真时间；控制器桥接 reset/get/set/step/debug；网络和 Tk 只消费状态快照、提交命令。
- Boundary：物理/实验核心不依赖 Tk/网络/真实硬件；单进程单 C 实例，A/B 顺序运行；UI、网络阻塞不得改变控制积分步长，后台不调用 Tk。
- Test Seam：解析自由落体/悬停/推力力矩方向/执行器滞后/步长减半；DLL 对直接 C harness；四环参数到输出和轨迹；真实 DronePanel 与 TCP 端到端；暂停、重连、复位、A/B、退出、布局截图。
