# 近水平 XY 磁航向辅助（CFG v27）

## 解决的问题

板载 QMC5883L 的 Z 轴在机体几乎不动时出现约 128 mG 的多档跳变，现有完整三维椭球校准因此拒绝。作者的目标是用磁力计**缓慢限制陀螺 yaw 的长期积分漂移**，接受约 5° 的短时航向误差。这条链使用已有水平转圈数据的 XY 圆心作相对磁航向参考；它不是三维硬磁/软磁校准，也不声称指向真北。

数据及复算：`data/analysis/mag-fit/2026-09-29/xy_candidate.json`（FLU X/Y 零偏 −3.725/+135.432 mG，XY 半径 268.292 mG）。使用 `tools/mag_xy_calibrate.py` 可从 310 点水平转圈 CSV 重算；随后 96 点相近姿态的相对磁航向标准差 0.461°。这些数据只覆盖一类未标注的 DCDC 工况，不证明负载变化或电机运行时的航向准确度。

## 与既有磁融合的关系

- 原 `MAGCAL` 仍表示完整三维磁场校准；原 `MAGFRAME`、四门融合判据及无磁回退不变。**不得**把本候选写成 `MAGCAL calibrated=1`。
- 独立的 `MAGXY` 校准位于 CFG v27 末尾。有效系数和独立实物轴向证明保存后，启用状态随记录持久化，上电自动请求纠偏。v26 及更早记录没有此块，迁移时显式关闭；无有效系数、轴向未验证或坐标契约版本不匹配也关闭。`MAGXY VERIFY CONFIRM` 不会把旧三维记录的轴向位设为已验证。
- Sensor_Task 20 Hz 的芯片磁场先按现有 `svc_mag` 转到 FLU；快照同时保存三维原始值和原三维校正值。近水平模式只读原始 FLU 值，扣 XY 圆心，在总倾角约 ≤5° 的连续 10 个**新**磁样本上平均 Z（只作 `MAGXY?` 诊断与预热门），然后把对齐后的 XY **只保留方向**（归一到 500 mG、Z 置 0）交给既有 `FusionAhrsUpdate()`，每个新的合格磁样本交一次。其他控制拍仍走 `FusionAhrsUpdateNoMagnetometer()`。现有 Driver 场强 200–800 mG 与 Fusion 磁方向 10° 拒绝门继续适用。
- 第一次合格输入把虚拟磁北对齐**当前** Fusion yaw；后续只用磁航向变化慢慢抵消积分漂移，不会在启用瞬间把 yaw 拉向真北。总倾角超过 5° 后清空 Z 平均窗；回到近水平须重新积累 10 个新样本。任何门未满足都无磁校正。

**Z 不喂给 Fusion（2026-09-30 改）。** 原先喂 10 点 Z 均值：实测 FLU Z 均值约 +567 mG，而当地地磁垂直分量朝下、在 FLU 里应为负，说明其中含很大的硬铁偏移。Fusion 用自己的重力估计做倾斜补偿，会把这个 Z 投影进航向；台架上 2.6° 的静态倾斜（`IMU?` 报的是扣过开机零点的角度，看不出来）就让每次重新对齐后 yaw 以约 93 s 的时间常数慢摆约 5°。Z 置 0 等于按水平 XY 定航向，与对齐口径一致；倾斜耦合只剩真实垂直分量漏进机体 XY 的那一份（约 V/H·倾角，5° 边界处约 6°）。归一到固定场强是因为 Fusion 只用方向，且 9/29 的 XY 圆心在台架上已偏约 65 mG（实测 |XY| 333 mG 对标定半径 268 mG），不归一时某些航向的 |XY| 会贴近 200 mG 场强门被误拒。转动中不直接平均机体系 XY，避免把真实航向变化抹掉。

## 命令与操作边界

以下仅说明**烧录并在无桨台架完成轴向物理核对后**如何由作者操作；本次软件工作没有向目标板发送命令。

```text
MAGXY SET -3.725 135.432 268.292
MAGXY?
MAGXY VERIFY CONFIRM     # 仅在实物确认芯片轴→FLU及左转符号后；RAM 立即启用
MAGXY COMMIT             # 写 CFG v27；重启后默认启用
MAGXY?
MAGXY ENABLE 0           # 上锁后临时关闭；若希望重启也关闭，再执行 COMMIT
MAGXY CLEAR              # 上锁后清空 RAM 候选；若希望清除 Flash，再执行 COMMIT
```

`MAGXY SET` 只装载并保持关闭；未配置或未完成独立轴向确认时 `ENABLE 1` 会拒绝。`VERIFY CONFIRM` 在已有有效系数时自动开启 RAM 纠偏；`COMMIT` 通过既有 A/B CFG 保存路径写入，须上锁，保存成功才在重启后默认启用。其他 CFG 保存命令也会保存当时的 RAM 配置。`MAGXY?` 报配置、有效轴向位、`ready`（送出磁样本次数）、`tilt`（近水平门拒绝次数）、10 点 Z 均值及最后结果。地面站现有 `MAGCAL` 横幅只表示**原三维模式**，不能用它判断 XY 模式是否工作。

## 已验证与待做

- 主机真实 C 测试：静止实录 96 点的输出 XY 模长恒为 500 mG、Z 恒为 0，XY 相对航向标准差低于 0.5°；旧记录默认关闭、v27 保存/读回自动启用、重复时间戳、倾角失效、轴向守卫、版本与命令均有定向覆盖。Vendor Fusion 的宿主联调在启用第一拍无 yaw 跳变；人为注入 0.05°/s 陀螺偏置的 120 s 仿真中，无磁约漂移 5.99°，试验模式约 2.27°。**合成陀螺偏置不构成真实飞行验收。**
- CFG v27 在主工作区通过配置往返、v26→v27 迁移、模拟掉电保留旧槽、命令守卫、真实 Fusion 节拍与 FLU 等定向测试；Debug 固件构建零警告，索引生成与检查通过，未改 CubeMX 生成代码。作者要求后停止全量回归；先前已启动的一次全量在并行光流页面的 `tests/test_mech.py::test_s6` 冻结哈希处停止，不能称为全量通过。
- **2026-09-30 台架静止漂移量化**（`data/analysis/mag-fit/2026-09-30/README.md`）：关磁纯陀螺 −2.16 °/min（另一次开机后 +0.17 °/min，随开机零偏标定与温度变化一个数量级）；开磁收敛后 ≤0.02 °/min、σ 0.02–0.05°。磁修正等效时间常数约 90 s（20 Hz 磁样本进 1 kHz 融合，增益稀释约 50 倍），稳态偏差 = 陀螺零偏 × τ。旧写法每次重新对齐后 yaw 慢摆 6°，其中 2–5° 是上文的 Z 倾斜投影错位；改 Z=0 后实机两次慢摆 0.26°/0.32°（只剩零偏 × τ），主机仿真 12 个对齐角 ≤0.05°（`tests/test_magxy_tilt_alignment.py`）。台架上 |XY−圆心| 333 mG 对标定半径 268 mG，圆心已偏约 65 mG，转向核对时须一并检查。
- 实机缺口：作者实物确认磁力计左转方向；同一姿态、同一接线下至少两种 TD8655 负载的 XY 航向均值 A/B；启用/关闭模式的静止 yaw 漂移和近水平缓慢转动对比；再决定是否进入电机运行/飞行试验。不能用软件结果替代这些证据。
