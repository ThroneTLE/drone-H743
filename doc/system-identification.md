# 光杆台架姿态辨识

入口：`python tools/drone_tcp_panel.py` → 系统辨识 → 角速度 / 角度内环。
需要 **SYSID ver=3 固件、记录 v3**（`SYSID?` 读回 `SYSID READY ver=3`、`SYSID SCHEMA ver=3 n=15`）和同版上位机。
实机状态以 PIPELINE 的 R-SYSID-1 为准；软件测试通过不等于杆上已验证。

## 一次辨识怎么做

1. **准备页填几何，只填一次**（下次打开会记住，存在 `data/identification/attitude/rig_settings.json`）：
   - 杆轴方向：绕 Y 轴 Pitch（90°）、斜向 ±45°，或自定义。选的是**实际旋转轴**，不是插杆的方向。
   - **杆中心到飞控板的垂直距离**（米，尺量，杆在飞控上方为正）。
   - **倾转轴到飞控板的垂直距离**：不是台架的杆，是舵机带电机组摆动的那根转轴（推力线过它）。
     默认从机体参数 `airframe.servo1_axis_z_m`（横滚）/ `servo2_axis_z_m`（俯仰）预填，与固件力矩模型同源；
     手填值与机体参数差 5 mm 以上会提示改成一致。在板下方填负数。
   - 可选：**台架刚度**（挂砝码，见下文）。
2. 遥控器**解锁，油门杆拉到最低**（舵机单独模式相反：**保持上锁**）。
3. 点 **「开始辨识」**。上位机读字段表和参数、逐条下发并核对回显后才发 `SYSID START`。飞控自己完成：
   **升油门 1.5 s → 稳定 1.5 s（最后 0.5 s 为零激励前导，照常采样）→ 激励 → 降油门 1 s**。
4. 结束后自动保存、自动分析、自动算建议参数。满意再选**试用比例**（50/75/100%，默认 50%）点
   「临时应用到飞控（RAM，不存 Flash）」，再用 RATE / ANGLE 各跑一轮验证。Flash 是否保存由作者在参数页决定。

实验类型：

| 类型 | 用途 | 默认 |
|---|---|---|
| 双脉冲 | **整定以它为准** | 8 s，幅值 0.065 rad/s（2026-09-27 力矩模型改后，保持舵机约 10° 摆幅） |
| 扫频 | 模型无关地看 1–3 Hz 凹口 | 0.5→6 Hz、12 s、0.022 rad/s；低频段舵机只摆 1–3°，落在回差里，**只作诊断** |
| 舵机单独（MODE 3） | 电机不转，单独测舵机响应、延迟、反作用和回差 | 摆幅 5°，**必须上锁** |

**幅值不要太小**：2026-09-27 幅值阶梯（0.03/0.06/0.10/0.20/0.15）拟合优度 15/35/52/82/85%。舵机摆幅低于约 5°
时回差（反向空程）让线性模型失效。激励幅值按"固件力矩单位"给出，舵机摆幅 ∝ 幅值 / 力臂，力臂变了要跟着改幅值。

## 油门归谁（作者 2026-09-26 授权）

- 解锁永远归飞手。FF/RATE/ANGLE 只在**已解锁、油门杆在最低**时接受开始；舵机单独只在**上锁**时接受开始。
- 运行中出现以下任一情况，**当拍把油门交还遥控器**（杆在最低即怠速）：飞手推油门杆、上锁、遥控失联；
  点「停止」；任一安全门触发（角度、杆轴残差、IMU、推力过期、执行器饱和、控制节拍）。
- 目标推力经分配器同一张推力查补表换成脉宽，再按"最高油门 %"封顶，封顶时 `SYSID THR ... capped=1`。
- 回落阶段数据已完整，此时停机按"完成"处理。结束或中止后舵机回中，直到上锁。
- 舵机单独模式**从不碰电机**；运行中一解锁立即以 `rc_arm` 中止。

## 固件力矩模型（2026-09-27 起）

倾转产生的力矩：`τ_roll = L_roll·T·sinβ`，`τ_pitch = L_pitch·T·sinα·cosβ`，
**力臂 L = 整机重心 z − 舵机转轴 z**（`airframe.cg_z_m − airframe.servo1/2_axis_z_m`，轴在重心下方为正）。
推力线过舵机转轴，所以力臂只看转轴到重心的距离，与桨盘在哪无关。原来的"0.145 m × 有效系数 0.569/0.581"
是 2026-07-25 按 1.367 kg 旧机体标的，机体变了没更新，按旧部件表重心算高估约 2.3 倍，已删除；
`airframe.{roll,pitch}_thrust_lever_arm_m` 退役（Flash 布局不变，PARAM 不再认）。

- **解锁闸门**：两个舵机转轴必须非零且有限；`|L| ≥ 1 cm`（`:near`）；L 与推力点在重心同侧（`:sign`）。
  ARM 报文 `airframe_missing=` 给出第一个不合格项。机体模型无效时舵机回中，不按错误力臂动。
- **速率环增益是 N·m 单位，等效软硬 ∝ 1/L**。重心或转轴一改，力臂变，舵机每单位误差的偏角跟着变，
  **必须重新辨识出增益**。机体参数页改这些量时会先显示"力臂 旧→新、增益等效变为 L旧/L新 倍"并确认。
- 2026-09-27 晚板上几何（部件表重心 −0.094558、转轴 −0.13）力臂 0.035442 m，默认增益与板上 Flash 增益已按
  横滚 ×0.42070、俯仰 ×0.42957 换算，飞行行为与改前一致。**作者实测重心为 −0.01**（力臂将是 0.12 m），
  部件表待核对后更正；更正后增益要按新辨识结果重设。
- `PARAM SET airframe.derived_auto 1` 当场重算派生值（以前要等重启）。

## 拟合模型：刚体单摆 + 舵机 + 反作用（"尾巴摇狗"）

杆在质心上方 d，重力像被动的"角度 P"把机体拉回自然平衡角（不一定是 0°）：

    I_杆·θ̈ + c·θ̇ + K·θ = G·u + ρ·ü，  u = 舵机二阶(ωs, ζs) ∘ 纯延迟 T ∘ τ_rec

- τ_rec 是固件按最终舵机脉宽和推力表反算的力矩（固件力矩单位），不是传感器读数。
- **ρ·ü 是舵机甩动电机组的反作用**：这台机上电机组重心在舵机轴下方约 11 cm，反作用很大，
  在台架上约 2.7 Hz 形成凹口（扫频直接测到），飞行中按纯力偶的最坏情况折算。它是限制增益的主因。
- K 默认取 m·g·d（d 量出来）；填了台架刚度就用实测 K。I_杆 由 K 与摆频定，I_质心 = I_杆 − m·d²。
- **κ = 真实绕质心力矩 / 记录力矩**，整定惯量 = I_质心 / κ。几何核对：κ_几何 = 由固件力臂和实测倾转轴算出的预期比例，
  **k = κ/κ_几何**只剩推力查补表与舵机标定的误差，超出 0.7–1.4（扣 2σ）拒绝给参数。
- 拟合频段 12 Hz 4 阶零相位，数据与模型同一滤波；开头 0.5 s 丢掉（起始瞬态），阻尼 c 放开（扫频过摆频时必须）。
  4 Hz 刚体积分读数只作对照，被 6/10 Hz 谱线证伪，不用于整定。
- 多轮联合拟合共享模型参数、每轮各解初值与零偏；**力矩模型或力臂不同的轮次不能联合**（单位不一样）。
- 扫频/宽带轮另报模型无关的凹口与摆频，与模型相差 >30% 视为结构可疑。

**舵机单独（电机不转）**：`I_杆·θ̈ + c·θ̇ + K·θ = −J·s̈ + H·s`，s 为记录的 `servo_tilt`（沿杆轴的指令倾角）。
J 是反作用惯量，H 是电机组质心偏离舵机轴带来的静力矩。结果给出舵机 ωs/ζs、纯延迟、J、H、
预测的带桨反作用 ρ = −J/(|L|·T)，并与同组带桨拟合对照；≥2 个幅值时按 J(A) = J·(1 − b/A) 估回差半宽 b。

**台架刚度（挂砝码，可选）**：电机不转，砝码 m_w 挂在与杆同高、离杆水平 x 处，读前挂 / 后挂 / 不挂三个角度
（ψ 斜向时按投影自动换算、页面提示读哪个角），`K = m_w·g·x / ((θ前 − θ后)/2)`。它把重力与线缆刚度一起量出来；
重心只在杆下 5 cm 时线缆刚度可与重力同量级，不量会把惯量和推力力矩一起低估（表现为 k 偏小）。

## 建议参数

在飞行对象 `e^{−sT}·舵机·(κ + ρ_f s²)/(I_质心·s)` 上回路整形：取满足**增益裕度 ≥ 6 dB、相位裕度 ≥ 45°** 的最大 kp，
ki = kp·ωc/5；角度环 P = 速率环穿越 × 0.25。D 为 0。陷波（见 `doc/rpm-notch.md`）的相位按最坏位置计入。

- 增益是**录制那一轮固件**的力矩单位。「临时应用」前重读飞控参数，按 `L_当前/L_录制` 逐轴换算 kp/ki/kd 与积分限幅；
  力臂读不出或异号就拒绝。「恢复原参数」同样换算，旧版（无力臂记录）的原参数文件拒绝自动恢复。
- 2026-09-27 下午两轮双脉冲（旧力矩模型、部件表重心）：kp 0.139 / ki 0.046（旧单位，今晚板上单位约 0.060 / 0.020），
  角度环 0.42，穿越约 0.27 Hz。**按实测重心 −0.01 重算结果完全不同**（角度环约 1.35），重心与台架刚度定下来之前不要上机。

不给建议参数的情况（页面写明原因）：数据不完整（中止、缺包、真实丢样 GAP/dropped、跨轮次或连接）；
带内拟合 < 72%；整定惯量不确定度 > 8%；k 越界或力矩极性不一致；舵机二阶参数贴边界（10 Hz 裕度无法核实）；
模型无关频响与模型相差 > 30%；刚体对照结构。

## 验证轮（RATE / ANGLE）

- 跟踪误差只算 **15 Hz 以下**（零相位低通后）；15 Hz 以上单列"振动噪声"和主频（约 107 Hz 桨振动）。
- 台架上有重力"弹簧"，而这组增益按飞行（无重力）设计、穿越只有约 0.3 Hz，**杆上跟不上是预期的**，
  验证主要看稳不稳、有无振荡；验证用双脉冲或低频激励，保持段 ≥ 1 s。
- 2026-09-27 RATE 验证（kp 0.139、ki 0.046，旧单位）稳定、无振荡，但积分限幅 0.01 N·m 顶住，基本不跟；
  积分限幅已按作者同意放到 0.05 N·m。
- 验证是否"对"看**模型复现**：同一 TWD 模型 + 固件控制器结构仿真这一轮，与实测相关 ≥ 0.9 即模型可信，
  再用模型预测真飞（`data/analysis/sysid-rig-params/2026-09-28/scripts/closed_loop_replay.py`）。
- **姿态整形（R-ATTFF-1，默认关）**：`coax.rate_out_notch_hz`/`_q`（横滚/俯仰力矩出口陷波，只滤 P+I−D）、
  `coax.rate_out_notch2_hz`/`_q`（第二级出口陷波，串在第一级之后滤同一信号，范围同第一级，Q 默认 1.0；
  用来压约 15 Hz 的舵机高阶动态/结构回路，配置记录 v25）、
  `coax.att_ref_wr_rad_s`/`coax.att_ref_delay_ms`（临界阻尼参考模型 + 角速度/力矩前馈，反馈跟延后参考）。
  RATE/ANGLE 验证轮与在飞控制器走同一实现；启用参考模型时把 `coax.rate_roll_ff`/`rate_pitch_ff` 设为 1，
  杆上前馈用 `SYSID INERTIA`，应设成 I_杆/G（G = κ·尺度）。开跑溯源 `SYSID start` 行尾带
  `ref_wr_mrad_s`、`ref_td_us`、`onotch_mhz`、`onotch_q_milli`、`onotch2_mhz`、`onotch2_q_milli`，
  页面存进 conditions.json。

## 出问题时看什么

| 横幅 / 日志 | 含义 |
|---|---|
| 没能开始：未解锁 / 油门杆不在最低 | 按提示操作后再点开始 |
| `ERR sysid servo mode needs disarmed` | 舵机单独模式要上锁 |
| 中止：rc_throttle_override / rc_arm | 推了油门杆 / 舵机单独时解锁了 |
| 中止：thrust_stale | 推力查表缺电池电压或双向 DShot 转速（舵机单独不查） |
| 中止：axis_residual | 机体没有只绕杆转：杆轴方向选错或没夹紧 |
| 中止：actuator_saturated | 带桨：所需力矩超出行程或推力（`SYSID SAT` 给细节）；舵机单独：摆幅碰到舵机标定行程，减小摆幅 |
| 中止：control_dt | 控制节拍异常，属固件问题，`SYSID DT dt_us=` 请保留 |

## 协议、记录与资源

| 用途 | 命令 / 行 |
|---|---|
| 配置 | `SYSID RIG / EXC ... servo_tilt_mrad= / RATE / INERTIA / LIMIT / MODE FF\|RATE\|ANGLE\|SERVO / THROTTLE target_n= max_pct=` |
| 完整状态 | `SYSID?`：READY、state、RIG、EXC、THR、LIMITS 共 6 行，以 LIMITS 结尾 |
| 轮询 | `SYSID THR?` 只回一行 THR |
| 运行中 | `SYSID PHASE`（舵机单独：preroll/excite/done）；`SYSID end` 结束行 |
| 候选增益 | `SYSID PARAM coax.rate_* / coax.att_* <值>`：只写 RAM，不排 Flash 自动保存；此后任何保存（别的 `PARAM SET` 排的自动保存、`SAVE`、各 COMMIT）对试用中的名字存的都是试用前的值（2026-09-28 起）。对同名发普通 `PARAM SET` = 定下来；写回原值、`LOAD`、`DEFAULTS`、重启都结束试用 |
| 试用查询 | `SYSID PARAM ?`（或不带参数）：`SYSID TRIAL n=<数>`，每个试用中的名字一行 `SYSID TRIAL name=<名> ram=<当前值> saved=<试用前的值>` |

- 数据走 `$X` 外层、0x2234 批量帧。**记录 v3**：前 13 个字段与 v2 相同，追加 `erpm_lower`（u16，×4 rpm）、
  `servo_tilt`（i16，×0.0001 rad，沿杆轴的指令倾角，正向 = 杆轴正向力矩）；`erpm` 为上桨真实电转速，
  批头 `ERPM_VALID` 表示两路转速有效（0 且有效 = 确实停转）；`SERVO`（0x0080）等模式标志在开跑时锁存。
  每条 30 B，满批 7 条。上位机 v1/v2/v3 都能解。
- 控制拍只写环形缓冲，文本和发送在低优先级任务里；没有新增 RTOS 任务、DMA 或 CubeMX 改动。
- 每轮自动保存到 `data/identification/attitude/YYYY-MM-DD/rod_<时间>_<标识>/`：`samples.csv`、`conditions.json`
  （含参数回显，用于判断力矩模型与力臂），分析后加 `fit.json`、`report.md`，联合分析加 `fit_joint.json`。
