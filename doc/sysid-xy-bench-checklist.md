# 水平槽 XY 辨识上台清单（R-XYID-1）

2026-09-30 晚按上台前排查（端到端仿真彩排、固件预演审查、地面站流程彩排）整理。台架：机体横杆两端各被上下两根
碳杆点接触夹住，槽上方封闭；杆方位 ψ = −45°（前—右），+u = 机头**左前方** 45°（FLU u = (+0.707, +0.707)）。

分工：**作者**摆放、手推、解锁/开始/停止；**AI**经地面站接口读数、下发只写 RAM 的试用增益、分析。

## 0. 摆放与量尺（上锁，约 3 分钟）

1. 机体放在槽的**中间**；量起点到两端挡块的距离 L₁、L₂。出窗余量 `win = min(L₁, L₂) − 30 mm`（30~400）。
   软停只清倾角、靠摩擦滑停，速度快时会按 `位移 + v²/0.4` 提前停，所以 win 越大越从容。
2. **偏航自由度**：用手把横杆一端往前、另一端往后推。能明显转动 → 开跑前把机体摆正、两端对齐；辨识不控偏航，
   偏航超过 15° 会软停（`xy_yaw_limit`），页面实时读数里有「偏航」。
3. 地面站「角速度 / 角度内环」页的杆轴方位选「斜向 −45°（前—右）」。

## 1. 光流与测距（上锁，AI 读数）

- `FLOW?`：`valid=1`、`quality` ≥ 45（越高越好，静止时实测 66）。
- **尺度核对**：尺量光流模块离地高度，与 `dist_mm` 比，差 10% 以内算对（光流速度 = 角速度 × 这个距离）。
  明显偏小说明测距打到了台架横梁，光流尺度会按同样比例错，要挪开或遮住横梁。
- 页面「XY 速度 / 位置环 → 准备」的实时读数应为「光流有效」。

## 2. 手推核对方向与尺度（上锁，最关键的一步）

作者沿槽把机体向 **+u（机头左前方）** 推约 100 mm，AI 在推前、推后各读一次 `FLOW?` 的 `disp_x_mm/disp_y_mm`
（里程计，上锁时照样累计），投影到 u、n。上锁低油门时导航位置每拍清零，所以**不要看页面的「沿 u 位置」**（恒为 0）。
估计器每拍被清零后只吸收约 80% 的光流测量（初始速度方差 0.25、光流噪声 0.25 m/s），读数会偏小约两成——
**这一步只看符号和沿 u / 垂直的比例**，尺度由第 1 步的测距对尺量来核。

| 沿 u | 垂直分量 | 结论 |
|---|---|---|
| 正，约 +80 | ≈ 0 | 正确，继续 |
| 负，约 −80 | ≈ 0 | 方向反了 180°（光流安装方向或 ψ）——**停**，先修 |
| 与垂直分量大小相当 | 同量级 | ψ 差 45° |
| ≈ 0 | 约 ±80 | ψ 差 90°（多半选成了 +45°）——倾角会推在被杆挡住的轴上 |

## 3. 第一轮：tilt（开环，看对象）

- 默认 0.07 rad × 400 ms × 3 对；托住推力用「读取学到的悬停推力」（竖直槽学到 14.25 N）。
  **第一轮幅值看窗口**：win ≥ 200 mm 用默认 0.07；win 只有 150 mm 时先用 0.06——仿真里摩擦偏轻（静/动 0.15/0.1）时
  0.07 会在最后半周期被预测出窗门软停（被停的一轮页面不给分析），0.06 走完约 104 mm。实测摩擦出来后再定。
- 看结果区：**增益为正**（推力大于重量时会显示 ≈ 1.2~1.3，属正常）、动摩擦、静摩擦门槛角、光流滞后。
  - 增益为负 → 方向反了，回第 2 步。
  - 「整轮没滑动」→ 幅值加到 0.09~0.10 再跑。
- 可选：托住推力取 重量 / 重量+1 N / 14.25 N 各跑一轮，比静摩擦门槛角，选最小最稳的（推力偏离重量只改变压哪根碳杆，
  但会改变摩擦）。

## 4. 闭环：vel、pos（需要试用增益）

- 板上 Flash 增益（pos_x_kp 0.9、vel_x_kp 2.0、vel_x_ki 0.6）在静摩擦 0.3 m/s² 下**推不动**（仿真跟上 0/4）。
  AI 用 `SYSID PARAM` 只写 RAM 试用 `coax.pos_x_kp 1.2`、`coax.vel_x_kp 3.0`、`coax.vel_x_ki 3.0`（重启即恢复；
  仿真：两档摩擦 4/4 跟上，无摩擦超调 21~35%、不出窗）。按第 3 步实测的摩擦再微调。
- 先 vel（默认 0.06 m/s），再 pos（默认 0.08 m、平台 3 s；pos 幅值 ≤ 0.7×win）。看「跟上 n/4」、上升时间、超调。
- 页面把当前试用值写进本轮存档；辨识结论是**带摩擦的台架**上的，不直接等于飞行增益。

## 5. 软停对照

| 原因 | 含义 | 先查 |
|---|---|---|
| `xy_window` | 位移模长 + 预计滑行 > 出窗余量 | 起点是否居中、幅值/win；记录里 pos_perp 大 → ψ 错 |
| `xy_overspeed` | 速度 > 0.4 m/s | 多半方向反了（闭环正反馈），回第 2、3 步 |
| `xy_yaw_limit` | 偏航 > 15° | 摆正、两端夹持松紧一致 |
| `xy_flow_invalid` | 光流连续失效 > 200 ms | 起转振动下的光流质量、遮挡、测距 |

开跑前检拒绝时页面会给具体中文原因；`flow invalid (vel_valid=… height_valid=… age_ms=…)` 看括号里哪项是 0。

## 6. 别在开跑那 1~2 秒里让 AI 发配置类命令

AI 接口插入的查询已不会干扰页面，但配置命令被拒时的 `ERR` 行无法区分来源，会被页面当成自己的拒绝。
