# 飞行油门模式（方案 B）契约

2026-10-01，作者选定方案 B："B"（问题见下）。固件与地面站都以本文件为准；改契约先改这里。

## 为什么改

旧逻辑是台架设计（`app_stabilizer.c`，`STABILIZER_RC_STABILIZE_MIN_PERCENT 70`）：

- 油门杆 < 70%：直通油门、**舵机锁中位、无姿态控制**；≥ 70% 才进稳定混控。
- 定点（CH6 低）下杆只给爬升率，按油门通道标定**中点**为零（`norm`∈[−1,1]）；作者遥控未标定，中点 1500=物理 50%，
  所以 ≥70% 时永远在爬（70%→+0.12 m/s），升到 `STABILIZER_Z_REF_MAX_M`(0.40 m) 上限；**稳定状态下无法下降**，
  降落只能拉到 70% 以下＝瞬间失去姿态控制、从 0.4 m 掉下。
- 角度模式（CH6 高）杆位经推力表直接换总推力，悬停约 90% 杆位；与定点模式的杆位语义不连续。
- 推力余量小：悬停 14.25 N ≈ 满电最大推力的 88–90%。

## 范围与选择

- 新状态机只管"遥控手飞"。下列任一在跑时**完全旁路**新状态机，沿用旧语义（旧 70% 判定、直通分支、它们各自的推力来源）：
  `sysid_running`、`ident_running`、推力台、桨叶旋向、舵机标定。它们结束时新状态机强制回 LANDED。
- 模式开关 `THRMODE FLIGHT|LEGACY`（只存 RAM，上电＝FLIGHT）；LEGACY＝逐位保持旧行为（含 70% 门限），供手动台架用。
  `THRMODE?` 回 `THRMODE mode=flight|legacy state=disarmed|landed|spoolup|flying zone=low|descend|hold|climb xy=pos|vel|angle thr_x1000=<t01·1000> h_mm=<相对高度>`（`xy` 为 CH6 三档）。
  LEGACY 逐位保持旧 CH6 判定（> 50% 即角度，无速度保持档）。

## 杆位分区（用 `rc.throttle_01`，按标定 min/max，**不依赖中点标定**）

| 区 | 范围 | 定点模式（CH6 低）爬升率 |
|---|---|---|
| LOW | t < 0.10 | −V_DN（并参与落地判定） |
| DESCEND | 0.10 ≤ t < 0.40 | −V_DN·(0.40−t)/0.30 |
| HOLD | 0.40 ≤ t ≤ 0.60 | 0（定高） |
| CLIMB | t > 0.60 | +V_UP·(t−0.60)/0.40 |

V_UP = 0.30 m/s，V_DN = 0.20 m/s（常量）。高度目标仍夹在 [0, `STABILIZER_Z_REF_MAX_M`] 与"实测 ±`STABILIZER_Z_POS_ERR_MAX_M`"内（沿用）。

## 状态机（解锁且链路正常、未被旁路时）

- **DISARMED**：未解锁。解锁条件不变（含油门 ≤10%）。解锁后进 LANDED。
- **LANDED**：电机**地面跟杆慢转**——作者 2026-10-01 卸桨/手扶台架后："油门在底部基本不转，这样我没办法判定桨叶有没有异常，低速转也作为判断依据"，并在"解锁即怠转 / 只跟杆慢转 / 两者结合"中选**只跟杆慢转**：t<0.10 不转（解锁时杆最低，故解锁不转）；0.10..0.60 线性 `GROUND_MIN`(5%)..`GROUND_MAX`(30% ESC 行程，≈2.8 N，不到机重三分之一）；>0.60 停在 30%。杆位**不直接**当油门（有 30% 上限）；舵机居中；位置/高度参考与积分器复位（同旧低油门段）。
  杆在 CLIMB 区**连续 ≥ 0.30 s** 且 IMU 有效 → SPOOLUP。测距无效时也允许起飞（高度环按旧逻辑跟随测量），但 `THRMODE?` 要能看出。
- **SPOOLUP**（约 1.0 s）：姿态稳定开（水平：直接水平姿态目标 0/0，速度环不跑），总推力走 `manual_total_force`：
  `GROUND_MAX` 慢转推力 → 0.85·`coax.hover_thrust_n`（未设则用机重）线性爬升 1.0 s（起点＝起旋前 0.3 s 一直停在的 30% 慢转，衔接不掉速）。期间杆掉出 CLIMB 区（< 0.60）→ 回 LANDED（中止，电机回到按当前杆位的地面慢转）。
  爬完 → FLYING：高度目标＝当前相对高度、位置目标＝当前位置（同旧"首次进入稳定段"初始化）。
- **FLYING**（CH6 三段拨码，2026-10-01 作者："CH6中改为不是定点模式，改成速度为0闭环，也就是没有位置P"，
  选三档并确认"CH6是三段拨码"；开关量 s 按 CH6 标定 min..max 归一，中位实测 1503 us ≈ 0.50）：
  - CH6 低（s < 1/3，定点）：旧稳定混控＋定点＋定高，爬升率按上表。
  - CH6 中（1/3 ≤ s ≤ 2/3，速度保持）：同定点，但**水平不跑位置 P**——位置参考每拍跟到当前估计，
    速度目标只来自摇杆（回中＝0），速度环 PI 照常；定高与爬升率同定点。切回定点时从切换那一刻的位置起锁。
  - CH6 高（s > 2/3，角度，飞手接管，**PX4 自稳式手控油门**，2026-10-01 作者："这个姿态模式貌似也套用了位置模式的
    油门定高，我想让它更像 px4那个一样手控油门"）：
    - **起转**：LANDED 时杆先到过 LOW 区（< 0.10），之后 t ≥ 0.10 **当拍直接进 FLYING**，不经 0.30 s CLIMB 迟滞与 SPOOLUP 斜坡；
      LANDED 时杆在中位才拨到角度档不会直接起转（仍是地面慢转），须先把杆拉到底。每次落地后都要重新拉到底。
    - **推力**：`DRV_FlightThrottle_ManualForce`＝下式按 max(t, 0.10) 计算——空中杆到底**不停桨**，保底为 0.10 那一档（0.2·hover）。
    - **积分**：推力 ≥ 0.80·hover 时速率环积分照常（`manual_integrate`），以下每拍清零（地面不卷积分）；SPOOLUP 与 LEGACY 调试档仍每拍清。
    - **落地**：只认判据 2（t < 0.10 且相对高度 < 0.15 m 连续 0.5 s）→ LANDED 停桨；测距无效时不自动落地，靠上锁。
    - 姿态目标与推力映射：姿态目标来自摇杆（±20°，沿用），总推力 = 分段线性：t≤0.5 → hover·t/0.5；t>0.5 → hover+(max−hover)·(t−0.5)/0.5，
    max 取现有推力上限；使"杆在中位≈悬停"，与定点模式中位定高语义连续。
  - **落地判定 → LANDED**（满足其一）：
    1. 定点或速度保持（定高在跑）：相对高度 < 0.06 m 且爬升率指令 ≤ 0 且 |vz| < 0.10 m/s，连续 ≥ 1.0 s；
    2. 任意模式：t < 0.10 且相对高度 < 0.15 m，连续 ≥ 0.5 s（飞手收杆切断）。
  - 测距无效时不做 1. 的判定，只认 2.（相对高度未知时 2. 不成立→不会空中误判）。
- 遥控丢失：沿用（立即上锁、电机关）；上锁 → DISARMED。
