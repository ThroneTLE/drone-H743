# 历史资料使用规则

> [!CAUTION]
> 本目录不是当前事实源。历史文档可能对应不同固件、机械安装、舵机中心、坐标口径、
> 参数版本或实验条件。Agent 在引用任何数值、数据集、结论或命令前，必须先询问用户：
> **本次要采用哪一个日期、数据集、固件提交和硬件配置？** 未得到选择时只能列出候选，
> 不得自行挑一组历史数据当当前基准。

保留历史资料的目的，是追溯设计来源和实验条件，不是恢复旧实现。

## 保留内容

- `identification-and-tether-geometry-2026-07-25.md`：质量、几何、推力/舵机辨识与惯量估计。
- `nonlinear-balance-controller-2026-07-25.md`：控制器理论、初始模型和旧版本集成记录。
- `coaxial_drone_controller_comparison.pdf`：历史控制器比较资料。
- `2024050116133964(1)(1).pdf`：外部参考资料，使用前先确认文献身份和适用范围。

已删除的旧架构蓝图、旧控制器图解、已完成作业单和旧推进记录仍可通过 Git 历史查看。
恢复其中任何内容前，必须先与当前源码、`PIPELINE.md`、契约测试和用户选定的数据批次核对。
